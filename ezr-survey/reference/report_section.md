# Add a section-divider slide

A one-line section break: a slide on the template's "Section Header"
layout (falling back to a plain titled slide when the template has
none). Use a short, single-word label – `"DEMOGRAPHICS"`, `"RATINGS"`,
`"APPENDIX"` – to chapter a deck.

## Usage

``` r
report_section(doc, title, layout = "Section Header", master = NULL)
```

## Arguments

- doc:

  A document from
  [`report_new()`](https://mashud37.github.io/ezr-research/ezr-survey/reference/report_new.md).

- title:

  Section label.

- layout:

  Section layout name. Defaults to `"Section Header"`.

- master:

  Optional master name.

## Value

The updated document.
