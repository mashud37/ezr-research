# Add a paragraph of text to a report

Add a paragraph of text to a report

## Usage

``` r
report_add_text(doc, text, ...)
```

## Arguments

- doc:

  A document from
  [`report_new()`](https://mashud37.github.io/ezr-research/ezr-survey/reference/report_new.md).

- text:

  Text to add; a character vector becomes one paragraph (bullet) per
  element on slides.

- ...:

  Passed to
  [`officer::body_add_par()`](https://davidgohel.github.io/officer/reference/body_add_par.html)
  (docx only).

## Value

The updated document.
